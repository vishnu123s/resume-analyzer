\# Resume Analyzer



A simple Python project that analyses resume skills and gives suggestions.



\## Features



\- Detects Python, SQL, HTML, CSS and Cloud skills

\- Calculates Resume Score

\- Suggests missing skills



\## Technologies Used



\- Python



\## Example



Input:



Python SQL HTML



Output:



✅ Python Found

✅ SQL Found

✅ HTML Found

❌ CSS Missing

❌ Cloud Missing



Resume Score: 60/100
